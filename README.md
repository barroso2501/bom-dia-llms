# Se sua IA pudesse perguntar qualquer coisa para você / If your AI could ask you anything

Página estática bilíngue sobre um experimento pessoal: durante 33 dias, seis modelos de linguagem responderam a "bom dia" com uma pergunta qualquer.

- Português: `index.html`
- English: `en/index.html`

Os modelos aparecem anonimizados (LLM1–LLM6). Não há dados pessoais além das próprias perguntas.
Publicação: GitHub Pages, branch `main`, pasta raiz.
